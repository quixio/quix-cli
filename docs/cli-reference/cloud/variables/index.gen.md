# cloud variables

## Overview

Manage the project variables of an environment

**Aliases:** `variables`, `variable`, `vars`, `var`

**Usage:**

```
quix cloud variables [command] [options]
```

**Commands:**

- [delete](delete.md): Delete a project variable
- [get](get.md): Get a specific project variable
- [list](list.md): List the project variables of an environment
- [set](set.md): Create or update a project variable
