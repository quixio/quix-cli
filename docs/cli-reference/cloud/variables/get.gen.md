# cloud variables get

## Overview

Get a specific project variable

**Aliases:** `get`

**Usage:**

```
quix cloud variables get <key> [<workspace-id>] [options]
```

**Arguments:**

- `<key>`: The key of the variable
- `<workspace-id>`: The ID of the environment

**Options:**

- `-o, --output <json|table>`: Output type of the retrieved data
